Android 13 in 3 seconds

iOS does not let apps generate executable code at run time, the biggest obstacle to running Android on an iPhone. Twoyi translates Android's code into the iPhone's native code when it is built, and gets everything out of the chip.

FAQ

What is Twoyi?

Twoyi is an app that runs a complete, separate Android system on an iPhone, iPad or Android phone, with its own home screen, apps and data. The iOS version runs Android 13; the Android version runs Android 8.1, 13 or 17.

How is Twoyi different from QEMU, UTM and Husk?

QEMU and UTM emulate a whole computer; on iOS without JIT (UTM SE) they can only interpret code piece by piece, and JIT needs a computer attached for debugging or a tool such as StikDebug. Husk's translation layer runs a single game without booting Android, and relies on QEMU emulation for a full system. Twoyi emulates no hardware: its own runtime provides the Linux kernel interface Android needs, and Android code is translated ahead of time into native ARM64 code, so a complete Android 13 boots in about 3 seconds without JIT.

Do I need a jailbreak, JIT, root or ADB?

No. The iOS version needs no jailbreak and no JIT (no computer or debugger attached); the Android version needs no root and no ADB. Twoyi installs and runs as an ordinary app.

How do I install the iOS version?

Download the IPA and sign and install it with AltStore, SideStore, TrollStore or your own developer certificate. It needs iOS / iPadOS 15 or later.

Is it a cloud phone? Where is my data?

It is not a cloud phone: Android runs on your own device, with no rented server and no monthly fee. Apps you install in Twoyi, the accounts you sign in to and the data they create stay in Twoyi, separate from the apps on your phone; uninstalling Twoyi deletes them.

Which Android apps run?

Most 64-bit apps. 32-bit apps are not supported; apps that depend on specific hardware or use hardening and anti-debugging may not run. On Android, Google services can be installed with one tap in settings.

Is Twoyi free?

Yes. Twoyi is free to download and use.

Does Twoyi collect my data?

Twoyi has no accounts and contains no ad or third-party analytics SDKs. Apps inside Twoyi go online directly, as on any phone. See the privacy policy.

How is Twoyi related to Twoyi Twin (twoyi.ai)?

Twoyi Twin is an AI assistant built on Twoyi: it opens apps, taps and types on the Android system inside Twoyi to finish tasks for you. It is part of the Android version and needs your own model API key. See twoyi.ai.

Where do I report a problem?

Join the Telegram channel, where new versions are announced too, or email twsxtd@gmail.com. On iOS, the “Android has stopped” screen lets you share logs directly.
