常见问题

两仪是什么？

两仪是一个 App，在 iPhone、iPad 或 Android 手机上运行一个完整、独立的 Android 系统，有自己的桌面、应用和数据。iOS 版运行 Android 13，Android 版可运行 Android 8.1、13 和 17。

两仪和 QEMU、UTM、Husk 有什么不同？

QEMU 和 UTM 模拟一整台电脑；在 iOS 上不开 JIT 时（UTM SE）只能逐段解释执行，开 JIT 又需要连接电脑调试或借助 StikDebug 等工具。Husk 的翻译层直接运行单个游戏而不启动 Android，完整系统要靠 QEMU 模拟。两仪不模拟硬件，由自己的运行时直接提供 Android 需要的 Linux 内核接口，并在构建时把 Android 代码预先翻译成 ARM64 本机代码，所以无需 JIT 也能约 3 秒启动完整的 Android 13。

需要越狱、JIT、ROOT 或 ADB 吗？

不需要。iOS 版不需要越狱，也不需要 JIT（不用连电脑或开调试）；Android 版不需要 ROOT，也不需要 ADB。两仪像普通 App 一样安装和运行。

iOS 版怎么安装？

先安装苹果的 TestFlight 应用，再在 iPhone 或 iPad 上打开公开测试链接，点击安装即可。公开测试名额有限，满员时请下载 IPA，用 AltStore、SideStore、TrollStore 或自己的开发者证书签名安装。要求 iOS / iPadOS 15 或更高版本。

是云手机吗？数据存在哪里？

不是云手机：Android 在你自己的设备上运行，不租用服务器，没有月费。在两仪里安装的应用、登录的账号和产生的数据都留在两仪里，不和手机本身的应用混在一起；卸载两仪会一并删除。

能运行哪些 Android 应用？

大多数 64 位应用。不支持 32 位应用；依赖特定硬件或带有加固、反调试的应用可能无法运行。Android 版可以在设置里一键安装 Google 服务。

两仪会收集我的数据吗？

两仪没有账号系统，不含广告和第三方统计 SDK。两仪里的应用会像在普通手机上一样直接联网。详见 隐私政策。

两仪分身是基于两仪的 AI 助手：它在两仪里的 Android 系统上替你打开应用、点按、输入，完成任务。目前包含在 Android 版里，需要自带大模型 API Key。详见 twoyi.ai。
