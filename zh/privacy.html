隐私政策

适用于两仪 App（iOS 版与 Android 版）和 twoyi.app 网站 · 更新于 2026 年 11 月 18 日

一句话版本：两仪没有账号系统，不含广告和第三方统计 SDK，不把你在两仪里的应用和数据上传给我们。两仪里的应用会像在普通手机上一样自己联网。

1. 留在你设备上的数据

两仪里的 Android 系统，以及你在其中安装的应用、登录的账号和产生的数据，都保存在两仪的应用目录里。删除或卸载两仪会一并删除这些数据。

2. iOS 版

  • App 本身不向我们的服务器发送请求，不检查更新，不含统计或崩溃上报 SDK。
  • 只有当两仪里的 Android 应用使用相机、麦克风、定位或计步时，两仪才向 iOS 申请对应权限，并把 iOS 提供的数据交给这个 Android 应用。你可以随时在 iOS 设置里关闭。
  • 日志只在你点“分享日志”时打包，并通过系统分享面板交给你选择的应用。

3. Android 版

Android 版和两仪分身是同一个 App，适用 两仪分身的隐私政策。其中与两仪本身有关的要点：

  • 打开 App 时和你点“检查更新”时，App 会从 twoyi.ai 读取版本信息；你在设置里安装 Google 服务时，会从 twoyi.app 读取下载配置并从 GitHub 下载安装包。这些请求不带账号或设备标识。
  • 相机、麦克风、定位、蓝牙、通知等权限按需申请，用途是提供给两仪里的应用使用。
  • 只有使用两仪分身（AI）时，任务相关的屏幕内容才会发给你自己配置的模型服务商，详见上面的政策。

4. 两仪里的应用

你在两仪里安装的应用会直接联网，它们如何处理数据适用各自的隐私政策。

5. 本网站

twoyi.app 托管在 GitHub Pages 上，不使用 Cookie、统计或广告。GitHub 可能为安全和运维记录访问者的 IP 地址，适用 GitHub 隐私声明。下载链接指向 dl.twoyi.ai。

6. 儿童

两仪不面向未满 14 周岁的儿童提供服务。

7. 变更与联系

政策更新时，我们会修改本页顶部的日期，并在 Telegram 频道 发布说明。有任何问题，请联系 twsxtd@gmail.com。
